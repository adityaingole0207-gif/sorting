DSA Sorting Glossary

In-Place Algorithm

An algorithm that sorts the elements within the input array itself, requiring at most a small constant amount of auxiliary memory (O(1) extra space, or O(log n) call stack).

Stable Sort

A sorting algorithm that preserves the relative order of duplicate elements with identical keys as they originally appeared in the input.

Comparison Sort

An algorithm that determines order strictly through element-to-element comparisons (e.g. A < B). Theoretical information theory bounds state that no comparison sort can run faster than Ω(n log n) in the worst case.

Pivot

A selected benchmark element used in Quick Sort to partition the array into elements smaller than the pivot and elements greater than the pivot.

Heapify (SiftDown)

The operation that restores the binary max-heap property by sifting down a root node that is smaller than either of its child nodes until the heap invariant is satisfied.

Inversion

A pair of elements (arr[i], arr[j]) such that i < j but arr[i] > arr[j]. The number of inversions measures how far an array is from being sorted.

Recursion Depth

The maximum number of simultaneous stack frames created by recursive function calls. For balanced QuickSort, depth is O(log n); in worst-case it can reach O(n).

Big-O Notation

Mathematical notation describing the asymptotic upper bound of an algorithm's growth rate in terms of execution time or memory space as input size n approaches infinity.
